# Vath Bundavit Portfolio

One-page portfolio website for software engineering internship applications. Built with React, Vite, TypeScript, and Tailwind CSS.

## Features

- Responsive one-page layout with smooth section navigation
- Project cards with real screenshots and GitHub/live links
- Data-driven projects, skills, social links, and journey content
- Resume download served from `public/resume.pdf`
- Vercel-ready static build

## Run Locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Production Build

```bash
npm run build
```

The production output is generated in `dist/`.
